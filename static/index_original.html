Distance: per-frame distance from recorded car to calculated path · Mean deviation: cumulative average distance · Amber box: animated car position on the calculated path

How to use

1. Upload video, scrub to a frame where the car is visible.
2. Select car, drag a box on the video, then Track. (Prototype tracks the object you select; it does not auto-recognise vehicles.)
3. Start camera. Move your index finger: the amber ring is your cursor. Hover a cyan point, pinch thumb+index to grab it, move, release.
4. Editing the target never changes the recorded movement.
